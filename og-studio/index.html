OG Studio

August 2026 Tool, Generative, Brand systems

A generator for a brand's system graphics: dot fields, masses, hatched discs and arcs, rolled from a seed and exported as colour and greyscale pairs.

Open the tool

I built this so people on my team could make on-system graphics without waiting on a designer or digging up a source file. Every graphic comes from a seed, so anyone can get back to the one they liked by typing six characters.

The rules were measured from a reference set rather than invented: the grid pitch, the dot weight, and how the colour splits across the field. Locks hold a composition, a palette or the grain steady while everything else rerolls. Each export is a pair, the colour graphic and a greyscale twin with identical geometry.
